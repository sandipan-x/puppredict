# PupPredict

Free puppy weight calculator: predict your puppy's adult weight with the vet formula, breed-size curve adjustment, and growth timeline. No signup.

## Features
- Vet-formula predictor with breed-size growth-curve adjustment (toy to giant mature at different rates)
- 'Double at 16 weeks' cross-check tile for a second opinion on the projection
- Growth timeline with fully-grown-by ages and auto size-class classification
